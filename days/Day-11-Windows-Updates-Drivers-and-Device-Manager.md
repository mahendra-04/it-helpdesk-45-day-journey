# Day 11 - Windows Updates, Drivers, and Device Manager

**Status:** Lesson Completed

## Learning Objectives

- Understand Windows Update and driver support basics.
- Use Device Manager to identify driver and hardware status.
- Troubleshoot common update and driver-related issues.

## Concepts Learned

- Windows quality updates, feature updates, restart requirements, and update history.
- Device Manager warning icons and driver properties.
- Driver update, rollback, disable, uninstall, and scan for hardware changes.
- Relationship between drivers and hardware reliability.

## Real-World Help Desk Examples

- Audio stops working after a driver update.
- A webcam is missing from a meeting application.
- Windows update requires a restart and affects user productivity.

## Troubleshooting Workflows

1. Confirm the affected device, Windows version, and update timing.
2. Check Device Manager status and update history.
3. Test driver update or rollback using approved guidance.
4. Restart the device and verify the hardware works.
5. Document driver version, update state, and user confirmation.

## Documentation Examples

- Record device name, driver version, update KB number, and error code.
- Note whether rollback, update, or reinstall was performed.
- Include restart and validation results.

## Ticket Note Examples

**Issue:** User reported no audio after Windows update.

**Technician notes:** Checked sound settings, Device Manager, driver status, and update history.

**Resolution:** Rolled back audio driver and restarted device. Speakers and headset tested successfully.

## Key Takeaways

- Driver problems can look like hardware failures.
- Update history helps connect symptoms to recent system changes.
- Device Manager is a key evidence source for support tickets.
