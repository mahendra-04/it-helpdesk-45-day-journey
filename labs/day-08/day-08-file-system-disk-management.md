## Key Notes

A file is a saved item on a computer. A folder stores files and other folders. A file path shows the exact location of a file or folder.

The C drive is usually the main Windows drive. It contains Windows, apps, user folders, temporary files, and system files.

Disk Management is used to view drives, partitions, drive letters, and disk status. It should be used carefully because changing partitions or formatting drives can erase data.

Disk Cleanup and Storage Sense help remove unnecessary files. Downloads and personal user files should not be deleted without user approval.

OneDrive can sync Desktop, Documents, and Pictures. Sync issues can make users think files are missing.
