# Day 13 - Networking Basics

**Status:** Lesson Completed

## Learning Objectives

- Understand basic network components and support boundaries.
- Learn how devices connect to local and wide-area networks.
- Recognize common connectivity symptoms reported by users.

## Concepts Learned

- LAN, WAN, router, switch, modem, access point, firewall, and endpoint.
- Wired vs wireless connections.
- Network adapter, IP address, gateway, DNS server, and internet service basics.
- Difference between local device issues and broader network outages.

## Real-World Help Desk Examples

- One user cannot access the internet while nearby users can.
- Multiple users in one area lose network access at the same time.
- A device connects to Wi-Fi but cannot reach internal resources.

## Troubleshooting Workflows

1. Determine whether the issue affects one user, one area, or many users.
2. Confirm connection type and network name.
3. Check adapter status and physical or wireless connection indicators.
4. Test access to local and external resources.
5. Document scope, tests, and escalation path.

## Documentation Examples

- Record location, network name, connection type, and affected users.
- Include whether internet, internal apps, or both are unavailable.
- Note any outage indicators or escalation contacts.

## Ticket Note Examples

**Issue:** User reported no network access from office workstation.

**Technician notes:** Confirmed issue affected one device. Checked Ethernet link light, adapter status, and IP configuration.

**Resolution:** Reconnected loose Ethernet cable and verified access to internal and external websites.

## Key Takeaways

- Network troubleshooting starts with scope.
- Connection type and location are essential ticket details.
- Simple physical checks can resolve many connectivity issues.
