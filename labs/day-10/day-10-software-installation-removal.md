## Key Notes

Software means programs or apps that run on a computer. Examples include Chrome, Teams, Outlook, Zoom, Adobe Reader, Slack, VS Code, antivirus tools, printer utilities, VPN clients, and business apps.

Software installation means adding a program to a computer. Software removal means uninstalling a program that is no longer needed, broken, unsafe, conflicting, or not approved.

EXE files are general executable installers. MSI files are Microsoft Installer packages often used in business environments for managed deployment.

Some installations require administrator permission because they change system files, install drivers, add services, or affect all users.

In a company environment, software should come from approved sources. Random software from unknown websites can create security, licensing, compatibility, and support risks.

App repair can fix some programs without removing user data. Reset is stronger and may remove app data. A clean reinstall means uninstalling the app, restarting the computer, installing the approved version again, and testing it.

## Safe Troubleshooting Order

1. Identify the exact app name.
2. Ask what changed recently.
3. Check the error message.
4. Restart the app.
5. Check Task Manager for stuck processes.
6. Restart the computer if needed.
7. Check installed version.
8. Check updates.
9. Repair the app if available.
10. Reinstall from an approved source if authorized.
11. Escalate if the issue continues.

## Example Ticket Note

User reported Outlook would not open. Checked Task Manager and found Outlook process still running in the background. Ended the stuck process and relaunched Outlook. User confirmed Outlook opened successfully.
