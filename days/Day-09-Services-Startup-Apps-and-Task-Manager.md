# Day 09 - Services, Startup Apps, and Task Manager

**Status:** Lesson Completed

## Learning Objectives

- Use Task Manager to review performance and running processes.
- Understand Windows services and startup application impact.
- Identify safe support steps for performance-related complaints.

## Concepts Learned

- CPU, memory, disk, network, and GPU usage views.
- Processes, applications, startup apps, and service status.
- Startup impact and background application behavior.
- Difference between ending a task and stopping a service.

## Real-World Help Desk Examples

- A computer is slow after sign-in due to heavy startup applications.
- An application is frozen and must be safely closed.
- A required service is stopped and prevents an application from working.

## Troubleshooting Workflows

1. Confirm the symptom, timing, and affected applications.
2. Review Task Manager performance and startup impact.
3. Identify resource-heavy or unresponsive processes.
4. Restart applications or services only when safe and appropriate.
5. Document observations and changes made.

## Documentation Examples

- Record top resource-consuming process and observed usage.
- Note service name, status, and restart result.
- Include whether the issue recurred after restart.

## Ticket Note Examples

**Issue:** User reported computer was slow immediately after login.

**Technician notes:** Reviewed Task Manager startup tab and performance usage. Identified multiple high-impact startup apps.

**Resolution:** Disabled approved nonessential startup apps and restarted device. User confirmed faster sign-in and desktop response.

## Key Takeaways

- Task Manager provides fast evidence for performance troubleshooting.
- Startup app review can improve user experience without major system changes.
- Service changes should be handled carefully and documented clearly.
