# Day 4 - Peripherals and Printers

## Topic
Today I learned about computer peripherals, input and output devices, Device Manager, drivers, printer basics, print queue, Print Spooler, and common printer troubleshooting.

## Concepts Learned

### Peripheral
A peripheral is an external device connected to a computer.

Examples:

- Mouse
- Keyboard
- Monitor
- Printer
- Microphone
- Webcam
- Scanner
- Headset
- Speakers
- External hard drive

### Input Device
An input device sends information into the computer.

Examples:

- Keyboard
- Mouse
- Microphone
- Webcam
- Scanner

### Output Device
An output device gives information out from the computer.

Examples:

- Monitor
- Printer
- Speaker
- Headphones
- Projector

### Driver
A driver is software that helps the computer communicate with hardware or peripherals.

Simple meaning:

```text
Driver = translator between Windows and hardware
```

### Device Manager
Device Manager is used to view and manage hardware devices connected to the computer. It can show driver issues, disabled devices, unknown devices, and hardware warnings.

### Print Queue
A print queue is the waiting line or sequence of documents waiting to be printed.

### Print Spooler
Print Spooler is a Windows service that manages print jobs and the print queue.

### Default Printer
The default printer is the printer Windows automatically chooses when the user clicks Print.

## Important Note

A mouse is an input device, but it is not a sound input device. In sound settings, input device usually means microphone. Output device means speaker, headset, or monitor audio.

## Troubleshooting Practice

### Problem
User says the printer is not printing.

### User Impact
User cannot print required documents, which may delay work.

### Questions I Should Ask

1. When did the issue start?
2. Did anything change recently?
3. Which printer are you trying to print to?
4. Does the printer have enough ink or toner?
5. Does the printer have enough paper?
6. Is the printer connected to power?
7. Do you see any error message?
8. Are other users able to print?

### Possible Causes

1. Printer is powered off.
2. Printer has no paper.
3. Printer has no ink or toner.
4. Paper is stuck or jammed.
5. Wrong printer is selected.
6. Printer is offline.
7. Print job is stuck in the queue.
8. Printer driver issue.

### First Things I Would Check

1. Check if the printer is powered on.
2. Check if the correct/default printer is selected.
3. Check if other users can print.
4. Check paper level.
5. Check ink or toner level.
6. Check printer screen for error messages.
7. Check the print queue.
8. Restart printer if needed.

### What I Would Document

1. User name.
2. Issue reported.
3. User impact.
4. Questions asked.
5. Troubleshooting steps taken.
6. Cause found.
7. Fix applied.
8. Ticket status.
9. Whether escalation is needed.
