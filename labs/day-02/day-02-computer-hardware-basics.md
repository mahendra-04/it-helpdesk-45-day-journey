## Topic
Today I learned the basic physical parts of a computer and how they relate to IT Help Desk work.

## What Hardware Means

Hardware means the physical parts of a computer or technology device. If I can touch it, it is usually hardware.

Examples:

- Laptop
- Desktop computer
- Monitor
- Keyboard
- Mouse
- Printer
- Charger
- Webcam
- Headset
- RAM
- SSD
- Motherboard
- CPU

## Main Computer Parts

### CPU
CPU means Central Processing Unit. It is the main processing part of the computer. It processes instructions and performs tasks.

Example: When I open Chrome, Word, Teams, or any program, the CPU helps process those actions.

### RAM
RAM means Random Access Memory. It is temporary working memory. It helps the computer run active apps and tasks.

Example: Chrome, Teams, Outlook, and Word all use RAM while they are open.

### Storage
Storage is where files, apps, photos, videos, documents, and the operating system are saved.

Common storage types:

- HDD: Older and slower storage with moving parts
- SSD: Newer and faster storage with no moving parts
- NVMe SSD: Very fast storage used in many modern laptops

### Motherboard
The motherboard is the main circuit board. It connects the CPU, RAM, storage, ports, power, and other computer parts together.

### Power Supply / Charger
The power supply gives power to the computer. In a laptop, this is usually the charger and battery. In a desktop, this is the PSU.

### GPU
GPU means Graphics Processing Unit. It helps with display, videos, graphics, games, design software, and multiple monitors.

### Ports
Ports are connection points on a computer.

Examples:

- USB: keyboard, mouse, flash drive, printer, webcam
- HDMI: monitor, TV, or projector connection
- Ethernet: wired internet
- Audio jack: headset or speakers
- USB-C: charging, data transfer, display, or accessories depending on the device

## Laptop vs Desktop

### Laptop
A laptop is portable. It includes screen, keyboard, battery, touchpad, speakers, webcam, and computer parts in one device.

### Desktop
A desktop usually has separate parts: tower, monitor, keyboard, mouse, and power cable. It is easier to upgrade and repair than most laptops.

## Troubleshooting Scenario

### Problem
User reports that the computer is very slow.

### User Impact
User cannot work efficiently because apps, files, or system actions are taking too long.

### Questions I Should Ask

1. When did the slowness start?
2. How often does it happen?
3. What task is it stopping you from doing?
4. Does it start right after turning on the computer or only after you begin working?
5. Did you install any unfamiliar apps recently?
6. Is the fan loud or does the laptop feel hot?
7. Are other users having the same issue?
8. Did Windows update recently?

### Possible Causes

1. Too many background tasks.
2. Old laptop or old hardware.
3. Malware or unwanted software.
4. Windows updates running.
5. Too many startup apps.
6. High RAM usage.
7. Storage almost full.
8. Old HDD or disk issue.

### First Things I Would Check

1. CPU usage in Task Manager.
2. Memory/RAM usage in Task Manager.
3. Disk usage in Task Manager.
4. Storage space.
5. Startup apps.
6. Background tasks.
7. Windows updates.
8. Antivirus or security alerts.

### What I Would Document

1. User name.
2. Problem reported.
3. Impact of the problem.
4. Questions asked.
5. Troubleshooting steps taken.
6. Findings, such as high RAM, high CPU, or full storage.
7. Fix applied.
8. Current status.
9. Whether escalation is needed.
