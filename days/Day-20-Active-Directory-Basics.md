# Day 20 - Active Directory Basics

**Status:** Lesson Completed

## Learning Objectives

- Understand the purpose of Active Directory in business environments.
- Learn core identity concepts used in help desk support.
- Connect directory services to login, access, and security workflows.

## Concepts Learned

- Domain, domain controller, user object, computer object, group, OU, and authentication.
- Centralized identity management and policy application.
- Difference between local accounts and domain accounts.
- How help desk technicians support identity-related tickets.

## Real-World Help Desk Examples

- A user cannot sign in to a domain-joined workstation.
- A new employee needs standard group access.
- A computer account issue prevents normal domain authentication.

## Troubleshooting Workflows

1. Verify the username, device, domain, and sign-in location.
2. Check whether the issue is account-specific or device-specific.
3. Review basic account state, group membership, and lockout indicators.
4. Test sign-in after approved changes.
5. Document identity checks and escalation details.

## Documentation Examples

- Record username, device name, domain, and error message.
- Note whether the user can sign in elsewhere.
- Include access groups reviewed or modified with approval context.

## Ticket Note Examples

**Issue:** User could not sign in to domain workstation.

**Technician notes:** Verified username, checked account status, confirmed domain connectivity, and tested sign-in on another workstation.

**Resolution:** Account was active and domain connection was restored after network reconnection. User confirmed successful sign-in.

## Key Takeaways

- Active Directory is central to account and access support.
- Identity tickets need careful verification and documentation.
- Device, account, and network factors can all affect domain sign-in.
