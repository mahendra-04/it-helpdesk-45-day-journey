# Day 04 - Peripherals and Printer Support

**Status:** Lesson Completed

## Learning Objectives

- Understand how peripherals connect to Windows systems.
- Learn common printer support concepts and driver workflows.
- Build a practical process for troubleshooting device and print issues.

## Concepts Learned

- USB, Bluetooth, HDMI, DisplayPort, docking stations, keyboards, mice, webcams, and headsets.
- Printer drivers, print queues, default printer settings, and network printers.
- Device Manager status indicators and driver update options.
- Difference between local device issues and shared service issues.

## Real-World Help Desk Examples

- A headset microphone works in Windows but not in Teams.
- A printer job is stuck in the queue and blocks later jobs.
- A second monitor is not detected through a docking station.

## Troubleshooting Workflows

1. Confirm device connection type and recent changes.
2. Check power, cable seating, ports, and Windows device recognition.
3. Review driver status and application-specific device settings.
4. Restart the affected service or clear the print queue when appropriate.
5. Test again with the user and document the result.

## Documentation Examples

- Record printer name, queue status, driver name, and connection type.
- Note whether the issue affects one user, one device, or multiple users.
- Include tested ports, cables, and application settings.

## Ticket Note Examples

**Issue:** User could not print to shared office printer.

**Technician notes:** Verified printer power, network status, Windows default printer, queue status, and driver selection.

**Resolution:** Cleared stuck print job and restarted print spooler. Test page printed successfully and user confirmed printing worked.

## Key Takeaways

- Peripheral issues often involve cables, drivers, application settings, or queues.
- Scope matters because a single-user issue is handled differently from a shared printer outage.
- Printer tickets need clear device names and queue details.
