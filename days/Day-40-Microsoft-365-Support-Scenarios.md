# Day 40 - Microsoft 365 Support Scenarios

**Status:** Lesson Completed

## Learning Objectives

- Apply Microsoft 365 troubleshooting to common support scenarios.
- Separate account, license, service, and application issues.
- Document productivity support work clearly.

## Concepts Learned

- Outlook sync, Teams meetings, OneDrive sync, SharePoint permissions, license state, MFA, and service health.
- Browser vs desktop comparison testing.
- App cache, profile refresh, sign-out/sign-in, and repair workflows.
- User impact for productivity applications.

## Real-World Help Desk Examples

- Outlook desktop cannot send mail while webmail works.
- Teams meeting audio uses the wrong microphone.
- OneDrive has sync conflicts in a shared folder.

## Troubleshooting Workflows

1. Confirm account, license, app, platform, and error message.
2. Compare web and desktop behavior.
3. Review service health and whether multiple users are affected.
4. Repair app, refresh sign-in, check permissions, or escalate as appropriate.
5. Validate user workflow and document results.

## Documentation Examples

- Record app name, account, license state, platform, error message, and test outcome.
- Include whether browser access works.
- Note service health findings and user confirmation.

## Ticket Note Examples

**Issue:** User reported OneDrive sync errors for a SharePoint library.

**Technician notes:** Verified account, checked OneDrive sync status, tested SharePoint browser access, and reviewed folder permissions.

**Resolution:** Reconnected library sync and confirmed files showed healthy sync status.

## Key Takeaways

- Microsoft 365 issues are often layered across identity, license, app, and service health.
- Browser testing is a reliable comparison step.
- Productivity support should end with user workflow validation.
