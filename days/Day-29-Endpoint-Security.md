# Day 29 - Endpoint Security

**Status:** Lesson Completed

## Learning Objectives

- Understand endpoint protection concepts used in support environments.
- Learn common security controls on Windows devices.
- Recognize when endpoint alerts should be escalated.

## Concepts Learned

- Antivirus, firewall, device encryption, patching, endpoint detection, and safe browsing.
- Security alerts, quarantine, malware symptoms, and suspicious processes.
- Importance of keeping operating systems and applications updated.
- Device lock, screen timeout, and secure handling basics.

## Real-World Help Desk Examples

- A user receives a malware detection alert.
- Firewall rules block a required business application.
- A laptop must be verified as encrypted before remote use.

## Troubleshooting Workflows

1. Confirm alert source, timestamp, and affected device.
2. Check whether the user interacted with suspicious content.
3. Review endpoint protection status and update state.
4. Follow approved security escalation procedures.
5. Document alert details and user guidance.

## Documentation Examples

- Record device name, username, alert name, detection time, and action taken.
- Include endpoint tool status and whether the device is isolated.
- Document escalation queue and reference number when available.

## Ticket Note Examples

**Issue:** Endpoint protection displayed malware alert on user laptop.

**Technician notes:** Collected device name, alert text, timestamp, and user activity before alert.

**Resolution:** Confirmed alert was quarantined by endpoint protection and escalated details to security team for review.

## Key Takeaways

- Endpoint alerts should be handled carefully and documented precisely.
- Help desk support connects user communication with security escalation.
- Patch and protection status are core endpoint security details.
