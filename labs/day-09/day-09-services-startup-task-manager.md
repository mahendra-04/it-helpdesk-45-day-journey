## Key Notes

Task Manager shows what the computer is doing right now. It helps check running apps, background processes, CPU usage, memory usage, disk usage, network usage, and startup apps.

A process is a running app or background activity. Some processes are visible apps, while others run quietly in the background.

Startup apps open automatically when Windows starts. Too many startup apps can slow down login.

A Windows service is a background helper that supports Windows or apps. Examples include Print Spooler, Windows Audio, Windows Update, and Bluetooth Support Service.

Services should not be disabled randomly because this can break Windows features or company tools.

- Bluetooth device is not connecting

## Safe Troubleshooting Order

1. Ask what changed.
2. Open Task Manager.
3. Check CPU, memory, disk, and network usage.
4. Identify the top resource-using app.
5. Close or restart the app if safe.
6. Check startup apps.
7. Check Windows Update.
8. Restart the computer if needed.
9. Document findings.
10. Escalate if the issue repeats or a system process is involved.

## Example Ticket Note

User reported slow computer after login. Checked Task Manager and found high memory usage and multiple startup apps running. Reviewed startup apps and disabled nonessential items. Restarted computer and confirmed login performance improved.
