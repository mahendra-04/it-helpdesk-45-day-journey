# Day 24 - Microsoft 365 Basics

**Status:** Lesson Completed

## Learning Objectives

- Understand Microsoft 365 support areas common to help desk roles.
- Learn how accounts, licenses, apps, and service health connect.
- Recognize basic productivity support workflows.

## Concepts Learned

- Microsoft 365 accounts, licenses, admin center concepts, service health, and sign-in.
- Outlook, Teams, OneDrive, SharePoint, and Office apps.
- MFA, browser access, desktop apps, and sync behavior.
- Difference between account issues, application issues, and service issues.

## Real-World Help Desk Examples

- A user cannot open Outlook desktop but webmail works.
- A user has no license for a required Microsoft 365 app.
- Multiple users report Teams issues during a service incident.

## Troubleshooting Workflows

1. Confirm account, license, application, device, and browser behavior.
2. Test web access to separate account issues from desktop app issues.
3. Review service health when multiple users are affected.
4. Repair, update, or sign out and sign back in where appropriate.
5. Document app version, license state, and user confirmation.

## Documentation Examples

- Record app name, platform, account, license state, and error message.
- Note whether web version, desktop version, or both are affected.
- Include service health findings when relevant.

## Ticket Note Examples

**Issue:** User could not open Microsoft Teams desktop app.

**Technician notes:** Verified Microsoft 365 sign-in, checked web Teams access, confirmed license, and restarted desktop client.

**Resolution:** Signed user out and back into Teams desktop. User confirmed chat and meeting access worked.

## Key Takeaways

- Microsoft 365 support requires checking account, app, license, and service layers.
- Web access is a useful comparison point.
- Service health awareness prevents unnecessary device troubleshooting.
