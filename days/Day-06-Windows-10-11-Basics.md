# Day 06 - Windows 10/11 Basics

**Status:** Lesson Completed

## Learning Objectives

- Navigate core Windows 10/11 support areas confidently.
- Understand where common user and device settings are managed.
- Connect Windows interface areas to real help desk tasks.

## Concepts Learned

- Start menu, Settings, Control Panel, File Explorer, Taskbar, and Notification Center.
- System information, About page, installed apps, default apps, and accessibility settings.
- Windows accounts, profiles, updates, and device settings.
- Administrative tools used by support technicians.

## Real-World Help Desk Examples

- A user needs default app settings changed for PDF files.
- A device name and Windows version are needed for a support ticket.
- A user cannot find network, sound, display, or accessibility settings.

## Troubleshooting Workflows

1. Confirm the user's Windows version and device type.
2. Navigate to the relevant Settings or Control Panel area.
3. Review configuration, permissions, and recent changes.
4. Apply the required setting change and test with the user.
5. Document the exact menu path and result.

## Documentation Examples

- Record Windows edition, version, device name, and signed-in user.
- Include the settings path used to resolve the issue.
- Note whether administrator access was required.

## Ticket Note Examples

**Issue:** User reported PDF files opening in the wrong application.

**Technician notes:** Checked default app configuration in Windows Settings and confirmed current PDF association.

**Resolution:** Updated default PDF application and confirmed files opened correctly from File Explorer.

## Key Takeaways

- Windows support depends on knowing where settings live.
- Simple configuration changes can resolve many user productivity issues.
- Clear menu-path documentation helps future technicians repeat the fix.
