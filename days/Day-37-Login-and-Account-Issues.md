# Day 37 - Login and Account Issues

**Status:** Lesson Completed

## Learning Objectives

- Troubleshoot common login and account access issues.
- Understand how passwords, MFA, profiles, locks, and permissions affect access.
- Document identity-related work securely.

## Concepts Learned

- Password reset, account unlock, MFA registration, profile loading, and access permissions.
- Difference between device login, web login, and application login.
- Common causes of repeated prompts and failed sign-ins.
- Security boundaries for account support.

## Real-World Help Desk Examples

- A user cannot sign in after changing a password.
- MFA prompts are going to an old phone.
- A user can sign in to webmail but not to a Windows device.

## Troubleshooting Workflows

1. Verify the user's identity using approved steps.
2. Confirm the affected login point and exact error message.
3. Check account status, lockout state, MFA method, and device connectivity.
4. Reset, unlock, refresh credentials, or escalate as appropriate.
5. Document actions without recording sensitive secrets.

## Documentation Examples

- Record username, affected service, error message, verification method, and action taken.
- Note whether MFA method was updated or account was unlocked.
- Include user confirmation after sign-in testing.

## Ticket Note Examples

**Issue:** User could not sign in to Microsoft 365 after phone replacement.

**Technician notes:** Verified identity, reviewed MFA method, and assisted with approved MFA registration update.

**Resolution:** User completed MFA registration and signed in successfully to Outlook and Teams.

## Key Takeaways

- Login issues often involve identity, device, network, and MFA layers.
- Secure documentation is essential for account support.
- Testing across services confirms whether access is fully restored.
