## What Hardware Means

Hardware means the physical parts of a computer or technology device. If I can touch it, it is usually hardware.

Examples:

- Laptop
- Desktop computer
- Monitor
- Keyboard
- Mouse
- Printer
- Charger
- Webcam
- Headset
- RAM
- SSD
- Motherboard
- CPU

## Main Computer Parts

### CPU
CPU means Central Processing Unit. It is the main brain of the computer. It processes instructions and helps run programs.

Example: When I open Chrome, Word, or Teams, the CPU helps process those actions.

### RAM
RAM means Random Access Memory. It is temporary working memory. It helps the computer run active apps.

Example: If many apps are open at the same time, more RAM is used.

### Storage
Storage is where files, apps, and the operating system are saved.

Common storage types:

- HDD: Older and slower storage with moving parts
- SSD: Faster storage with no moving parts
- NVMe SSD: Very fast storage used in many modern laptops

### Motherboard
The motherboard is the main circuit board. It connects the CPU, RAM, storage, ports, power, and other parts together.

### Power Supply / Charger
The power supply gives power to the computer. In a laptop, this is usually the charger and battery. In a desktop, this is the PSU.

### GPU
GPU means Graphics Processing Unit. It helps display graphics, videos, games, and visual work.

### Ports
Ports are connection points on a computer.

Examples:

- USB: keyboard, mouse, flash drive
- HDMI: monitor or TV connection
- Ethernet: wired internet
- Audio jack: headset or speakers
- USB-C: charging, data, display, or accessories depending on device

## Laptop vs Desktop

### Laptop
A laptop is portable. It includes screen, keyboard, battery, touchpad, speakers, webcam, and computer parts in one device.

### Desktop
A desktop usually has separate parts: tower, monitor, keyboard, mouse, and power cable. It is easier to upgrade and repair than most laptops.

## Common Hardware Issues in Help Desk

- Laptop not turning on
- Screen is black
- Keyboard not typing
- Mouse not moving
- Battery not charging
- Computer is slow
- Fan is loud
- Device overheating
- USB device not detected
- External monitor not working
- Printer not responding
- Webcam or headset not detected

## Real-World Example

### Problem
User says: "My laptop is very slow."

### Possible Hardware-Related Causes

1. Low RAM.
2. Old HDD instead of SSD.
3. Storage is almost full.
4. Computer is overheating.
5. Too many apps are running.
6. Hardware is aging or failing.

### Questions I Should Ask

1. When did the laptop become slow?
2. Is it slow all the time or only when opening certain apps?
3. How many apps are open?
4. Is the fan loud?
5. Does the laptop feel hot?
6. Is the storage almost full?
7. Was anything installed recently?

## Troubleshooting Scenario

### Problem
User reports that their computer turns on but works very slowly.

### Possible Causes

1. Too many startup apps.
2. Not enough RAM.
3. Disk usage is high.
4. Storage is almost full.
5. Windows update is running.
6. Malware or unwanted software.
7. Old HDD.
8. Overheating.

### First Steps

1. Ask when the slowness started.
2. Open Task Manager.
3. Check CPU, RAM, and Disk usage.
4. Check startup apps.
5. Check free storage space.
6. Restart if needed.
7. Check for updates or scans running.
8. Document findings.
