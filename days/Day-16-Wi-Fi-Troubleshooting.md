# Day 16 - Wi-Fi Troubleshooting

**Status:** Lesson Completed

## Learning Objectives

- Understand common Wi-Fi issues in user support.
- Learn how signal, authentication, adapter settings, and saved profiles affect connectivity.
- Build a structured workflow for wireless troubleshooting.

## Concepts Learned

- SSID, signal strength, wireless adapter, authentication, saved profiles, and roaming.
- Difference between connected with no internet and unable to connect.
- Common interference and distance factors.
- Basic Windows Wi-Fi settings and adapter checks.

## Real-World Help Desk Examples

- A user can see the Wi-Fi network but cannot connect.
- A laptop connects in one room but drops in another.
- A saved Wi-Fi profile has outdated credentials.

## Troubleshooting Workflows

1. Confirm SSID, location, and whether other users are affected.
2. Check Wi-Fi toggle, airplane mode, and adapter status.
3. Forget and reconnect to the approved network when appropriate.
4. Test signal strength and compare with a known-working device.
5. Document location, SSID, authentication result, and test outcome.

## Documentation Examples

- Record SSID, device model, Windows version, and location.
- Note whether the issue follows the user, device, or physical area.
- Include authentication errors and adapter status.

## Ticket Note Examples

**Issue:** User could not connect to corporate Wi-Fi.

**Technician notes:** Confirmed SSID, checked airplane mode, reviewed adapter status, and removed outdated saved profile.

**Resolution:** User reconnected with current credentials and confirmed internet and internal app access.

## Key Takeaways

- Wi-Fi issues need both device and location context.
- Saved profiles can preserve old settings that cause repeated failures.
- Scope checks help separate user-device issues from wireless coverage issues.
