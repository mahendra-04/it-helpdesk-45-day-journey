# Day 41 - Resume, LinkedIn, and GitHub Profile

**Status:** Lesson Completed

## Learning Objectives

- Present IT support learning in a recruiter-friendly way.
- Align resume, LinkedIn, GitHub, and portfolio language.
- Highlight real support skills without overstating experience.

## Concepts Learned

- Support keywords, project evidence, achievement framing, and role alignment.
- How to describe Windows, networking, Microsoft 365, Active Directory, PowerShell, and ticketing skills.
- Importance of consistency across public profiles.
- Project-based proof for entry-level IT support readiness.

## Real-World Help Desk Examples

- A recruiter reviews a GitHub repository for evidence of consistent learning.
- A hiring manager scans for Windows, Microsoft 365, networking, and documentation keywords.
- A portfolio project helps connect learning to real support workflows.

## Troubleshooting Workflows

1. Identify target roles and common skill requirements.
2. Map completed learning topics to role-relevant keywords.
3. Write concise project descriptions focused on support outcomes.
4. Verify links and consistency across profiles.
5. Keep wording honest, specific, and professional.

## Documentation Examples

- Project summary: "Completed a 45-day IT Help Desk roadmap covering Windows, networking, Microsoft 365, Active Directory concepts, PowerShell basics, and ticketing workflows."
- Resume bullet: "Documented 45 daily support logs with troubleshooting workflows and ticket-style resolution notes."
- LinkedIn project line: "Built a public IT Help Desk learning repository with 45 completed logs."

## Ticket Note Examples

**Issue:** Public project needed professional presentation for recruiters.

**Technician notes:** Reviewed wording, aligned skills with support roles, and verified repository links.

**Resolution:** Project summary, roadmap, and final summary were organized for clear recruiter review.

## Key Takeaways

- Public project evidence should be clear, honest, and easy to review.
- Consistent language across platforms strengthens professional presentation.
- Completed learning logs can demonstrate reliability and support mindset.
