# Day 08 - File System and Disk Management

**Status:** Lesson Completed

## Learning Objectives

- Understand Windows file paths, folders, drives, and partitions.
- Learn basic Disk Management concepts used in support work.
- Troubleshoot common file access and storage capacity issues.

## Concepts Learned

- File Explorer, paths, extensions, hidden files, and common user folders.
- Drive letters, partitions, volumes, and Disk Management.
- Free space, disk cleanup, temporary files, and storage sense.
- File recovery awareness and safe handling of user data.

## Real-World Help Desk Examples

- A user cannot find a downloaded file.
- A workstation shows low disk space warnings.
- A new external drive appears in Disk Management but not File Explorer.

## Troubleshooting Workflows

1. Confirm the file path, drive letter, or storage warning.
2. Check available storage and disk layout.
3. Review user folder locations and file search options.
4. Apply safe cleanup or drive-letter corrections when appropriate.
5. Document file paths, cleanup actions, and available space after resolution.

## Documentation Examples

- Record drive letter, free space before and after cleanup, and affected folders.
- Note whether files were moved, restored, or left unchanged.
- Include user confirmation that required files are accessible.

## Ticket Note Examples

**Issue:** User reported low disk space warning on C: drive.

**Technician notes:** Checked storage usage, temporary files, downloads folder size, and installed application size.

**Resolution:** Removed approved temporary files and enabled Storage Sense. Free space increased and user confirmed system warning disappeared.

## Key Takeaways

- File and storage support requires careful handling of user data.
- Disk Management helps identify drive visibility and partition issues.
- Storage documentation should include before-and-after details.
