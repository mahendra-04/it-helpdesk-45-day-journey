## Key Notes

Windows Update installs security updates, bug fixes, feature updates, driver updates, Microsoft Defender updates, .NET updates, and sometimes firmware updates.

Updates are important because they keep Windows secure and stable, but they can also sometimes cause device or software issues.

Update history is useful when a problem starts after a recent update. It can show quality updates, driver updates, definition updates, feature updates, and failed updates.

A driver is software that helps Windows communicate with hardware. Examples include Wi-Fi drivers, audio drivers, graphics drivers, camera drivers, printer drivers, Bluetooth drivers, and USB drivers.

Device Manager is used to view hardware and driver status. A yellow warning icon usually means a device or driver problem. An unknown device usually means Windows detected hardware but does not have the right driver.

Driver rollback can return a device to a previous driver version if a new driver caused problems.

Optional updates should not be installed blindly. Firmware updates should not be interrupted.

## Safe Troubleshooting Order

1. Ask when the issue started.
2. Ask what changed recently.
3. Check Windows Update status.
4. Check restart requirement.
5. Check update history.
6. Open Device Manager.
7. Check for warning icons or unknown devices.
8. Restart the computer if needed.
9. Update, rollback, or reinstall a driver only if safe and approved.
10. Document findings.
11. Escalate if the issue continues.

## Example Ticket Note

User reported Wi-Fi option missing after recent update. Checked Airplane mode and confirmed it was off. Opened Device Manager and found Wi-Fi adapter with warning icon. Restarted device and reviewed update history. Escalated for driver review because issue continued.
