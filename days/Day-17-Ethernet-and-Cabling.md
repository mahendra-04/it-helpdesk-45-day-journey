# Day 17 - Ethernet and Cabling

**Status:** Lesson Completed

## Learning Objectives

- Understand wired network basics used in desktop support.
- Learn how cables, ports, docking stations, and link lights support diagnosis.
- Recognize when physical-layer issues should be escalated.

## Concepts Learned

- Ethernet cables, RJ45 connectors, switches, wall jacks, patch panels, and docking stations.
- Link lights, speed indicators, and network adapter status.
- Cable damage, loose connections, port failures, and docking station issues.
- Difference between physical connection failures and IP configuration issues.

## Real-World Help Desk Examples

- A workstation loses network access after being moved to another desk.
- A docking station has power but no wired network connection.
- A wall jack works for one device but not another.

## Troubleshooting Workflows

1. Check cable seating, wall jack, device port, and docking station.
2. Confirm link lights and Windows adapter status.
3. Swap one cable or port at a time using known-good hardware.
4. Compare wired and wireless connectivity when available.
5. Escalate cabling or switch-port issues with location details.

## Documentation Examples

- Record desk location, wall jack label, cable tested, and device used.
- Note link-light behavior and adapter status.
- Include whether the issue follows cable, device, dock, or port.

## Ticket Note Examples

**Issue:** User reported no wired network connection at desk.

**Technician notes:** Checked cable, wall jack, link lights, and docking station. Tested same laptop on another known-working port.

**Resolution:** Issue isolated to wall jack. Escalated to network team with jack label and test results.

## Key Takeaways

- Physical network troubleshooting depends on careful variable isolation.
- Location and port labels are important escalation details.
- Wired issues often require coordination with network or facilities teams.
