# Day 26 - Teams, OneDrive, and SharePoint

**Status:** Lesson Completed

## Learning Objectives

- Understand common support issues for Teams, OneDrive, and SharePoint.
- Learn how sync, permissions, cache, and account state affect collaboration.
- Document collaboration app issues clearly for users and escalation teams.

## Concepts Learned

- Teams sign-in, meetings, audio/video devices, cache, and notifications.
- OneDrive sync status, paused sync, conflicts, storage, and file availability.
- SharePoint site permissions, file sharing links, and browser access.
- Relationship between Microsoft 365 identity and collaboration tools.

## Real-World Help Desk Examples

- A user cannot join a Teams meeting with audio.
- OneDrive shows a sync error on a project folder.
- A SharePoint document opens for one user but not another.

## Troubleshooting Workflows

1. Confirm the app, account, device, browser, and error message.
2. Test web access to compare with desktop app behavior.
3. Check permissions, sync status, cache, and device settings.
4. Restart app, refresh sign-in, or repair sync when appropriate.
5. Document affected files, links, sites, and user confirmation.

## Documentation Examples

- Record Teams meeting link, OneDrive folder path, or SharePoint site URL when relevant.
- Note whether browser access works.
- Include permission owner or site owner details for escalation.

## Ticket Note Examples

**Issue:** User could not access a SharePoint folder.

**Technician notes:** Verified user account, tested direct link, checked group membership, and confirmed other users could access the folder.

**Resolution:** Added user to approved SharePoint access group. User confirmed folder opened in browser and synced through OneDrive.

## Key Takeaways

- Collaboration app support often involves identity, permissions, and sync state.
- Browser testing helps identify desktop client issues.
- File path and site details are important for escalation.
