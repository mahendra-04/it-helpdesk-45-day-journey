# Day 02 - Computer Hardware Basics

**Status:** Lesson Completed

## Learning Objectives

- Identify core computer hardware components and their support relevance.
- Understand how CPU, RAM, storage, motherboard, power, and cooling affect performance.
- Connect common hardware symptoms to likely causes.

## Concepts Learned

- CPU, RAM, SSD, HDD, GPU, motherboard, PSU, battery, display, and ports.
- Device specifications and how to gather them for support.
- Difference between performance limitations and hardware faults.
- Safe handling habits for user devices and peripherals.

## Real-World Help Desk Examples

- A laptop runs slowly because available RAM is low during normal work.
- A device will not power on due to an adapter, battery, or charging port issue.
- A user needs help identifying whether a docking station, monitor, or cable is causing display failure.

## Troubleshooting Workflows

1. Confirm the device model, power state, and connected peripherals.
2. Check visible indicators such as lights, fan noise, battery status, and display output.
3. Review system specifications and resource usage.
4. Test with known-good cables, chargers, or ports when available.
5. Document the suspected component and escalation details.

## Documentation Examples

- Capture device make, model, serial number, and warranty status when available.
- Record tested accessories and whether the issue follows the device or accessory.
- Include user impact and urgency for hardware replacement decisions.

## Ticket Note Examples

**Issue:** User reported laptop would not charge.

**Technician notes:** Checked wall outlet, power adapter, charging cable, charging port, and battery indicator. Tested with known-good adapter.

**Resolution:** Confirmed original adapter was faulty. User was issued a working adapter and confirmed the laptop was charging.

## Key Takeaways

- Hardware support starts with careful observation and safe testing.
- Known-good part testing helps isolate faulty components.
- Accurate asset details improve repair, replacement, and escalation workflows.
