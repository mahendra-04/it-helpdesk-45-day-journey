# Day 30 - Backup and Recovery

**Status:** Lesson Completed

## Learning Objectives

- Understand backup and recovery concepts in user support.
- Learn how restore points, file history, cloud sync, and shared storage affect recovery options.
- Communicate data recovery expectations clearly.

## Concepts Learned

- Backup types, restore points, file recovery, version history, cloud sync, and business continuity.
- Difference between backup, sync, and archive.
- Recovery point objective and recovery time awareness.
- Safe handling of accidental deletion and data loss reports.

## Real-World Help Desk Examples

- A user accidentally deletes an important document.
- OneDrive version history is needed to restore an earlier file.
- A system restore point is considered after a faulty driver update.

## Troubleshooting Workflows

1. Confirm what data is missing, when it was last available, and where it was stored.
2. Check recycle bin, version history, cloud sync, and backup availability.
3. Restore the safest verified copy when approved.
4. Confirm file integrity with the user.
5. Document source, restore method, and final location.

## Documentation Examples

- Record file name, path, deletion time, recovery source, and restored location.
- Note whether the file was restored from recycle bin, version history, or backup.
- Include user confirmation that the restored data is correct.

## Ticket Note Examples

**Issue:** User accidentally deleted a spreadsheet from OneDrive.

**Technician notes:** Confirmed file name and location, checked OneDrive recycle bin, and reviewed version history.

**Resolution:** Restored latest valid copy from OneDrive recycle bin. User opened file and confirmed contents.

## Key Takeaways

- Backup and sync are not the same, and users may need that explained clearly.
- Recovery work should protect existing data and confirm file integrity.
- Documentation must include file paths and restore source.
