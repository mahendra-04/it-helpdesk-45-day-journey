# Day 42 - Technical Interview Preparation

**Status:** Lesson Completed

## Learning Objectives

- Prepare concise answers for common IT Help Desk technical topics.
- Explain troubleshooting steps clearly under interview conditions.
- Connect project learning to role expectations.

## Concepts Learned

- How to explain DNS, DHCP, IP addresses, VPN, Active Directory, Microsoft 365, and Windows support tools.
- Scenario-based troubleshooting structure.
- Importance of asking clarifying questions before choosing a fix.
- How to describe escalation and documentation habits.

## Real-World Help Desk Examples

- Interview question: "How would you troubleshoot a user who cannot connect to Wi-Fi?"
- Interview question: "What steps would you take for a slow computer?"
- Interview question: "How do you handle a password reset securely?"

## Troubleshooting Workflows

1. Restate the user issue and ask clarifying questions.
2. Check scope and recent changes.
3. Start with simple, low-risk checks.
4. Use tools and evidence to isolate the cause.
5. Explain resolution, documentation, and escalation steps.

## Documentation Examples

- Technical answer structure: symptom, scope, checks, evidence, fix, validation, documentation.
- Escalation example: include user, device, logs, command output, business impact, and attempted steps.
- Windows example: mention Task Manager, Event Viewer, Device Manager, and update history when relevant.

## Ticket Note Examples

**Issue:** Interview scenario required explaining slow computer troubleshooting.

**Technician notes:** Structured answer around user impact, Task Manager, storage, startup apps, updates, and security checks.

**Resolution:** Created a clear technical response with validation and documentation steps.

## Key Takeaways

- Strong interview answers show process, not memorized fixes.
- Clarifying questions demonstrate support maturity.
- Explaining documentation and escalation makes answers more realistic.
