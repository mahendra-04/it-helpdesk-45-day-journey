# Day 01 - IT Help Desk Foundation

**Status:** Lesson Completed

## Learning Objectives

- Understand the purpose of an IT Help Desk in an organization.
- Identify common support roles, escalation paths, and service desk responsibilities.
- Learn how professional ticket documentation supports reliable user service.

## Concepts Learned

- Help Desk, Service Desk, Desktop Support, and Technical Support role differences.
- Tier 1, Tier 2, and escalation workflows.
- Incident intake, prioritization, resolution, and closure.
- Importance of user communication, impact assessment, and documentation.

## Real-World Help Desk Examples

- A user cannot sign in before a meeting and needs urgent account support.
- A new employee needs access to email, shared drives, and required applications.
- A recurring printer issue needs clear documentation so the next technician can respond faster.

## Troubleshooting Workflows

1. Confirm the user, device, location, and affected service.
2. Ask what changed before the issue started.
3. Reproduce or verify the symptom when possible.
4. Apply the simplest safe fix first.
5. Document the result and confirm the user can continue working.

## Documentation Examples

- Record user impact, affected system, time reported, and business urgency.
- Note steps taken, test results, and any escalation details.
- Keep the tone factual, concise, and professional.

## Ticket Note Examples

**Issue:** User reported inability to access work email.

**Technician notes:** Verified user identity, confirmed account status, checked service availability, and tested sign-in from a browser.

**Resolution:** User regained access after password reset and MFA verification. User confirmed email access was working.

## Key Takeaways

- A strong help desk process depends on clear communication and structured troubleshooting.
- Good ticket notes make support work repeatable and easier to escalate.
- User impact should guide priority and response.
